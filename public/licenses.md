# Open source licenses

Credits and license information for the open source software and services that power Crosspost.

## Open source libraries

Crosspost is built on open source software, including:

- **Supabase** (Supabase, Inc.) — MIT (client libraries) — accounts and sign-in.
- **TanStack Start, TanStack Router, TanStack Query** — MIT — routing, data fetching, and server rendering.
- **React** — MIT — user interface.
- **Web Awesome** (Font Awesome) — open source design system components.

The full list of libraries and their licenses is on the [licenses page](https://tweet.mikedemo.dev/licenses). This project's own source is MIT licensed: [Mike-Demo/tweet-caster-magic](https://github.com/Mike-Demo/tweet-caster-magic).

## Services

- **hCaptcha** (Intuition Machines, Inc.) — proprietary service — bot protection on the sign-in and sign-up form.
- **tweet.app API** (Operation Bluebird, Inc.) — source of the posts this app reposts, used with each person's own account.
- **X API** (X Corp.) — posts are published to X using each person's own X developer account and keys. This app is not affiliated with X Corp.
