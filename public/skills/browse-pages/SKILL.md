# Browse Crosspost Public Pages

Use this skill when you need to read or index Crosspost's public informational pages.

## Public pages

- Home: https://tweet.mikedemo.dev/ — what Crosspost does, current service status, sign in or register.
- Setup guide: https://tweet.mikedemo.dev/docs/setup
- Posting: https://tweet.mikedemo.dev/docs/posting
- Tokens and keys: https://tweet.mikedemo.dev/docs/tokens
- Security: https://tweet.mikedemo.dev/docs/security
- Troubleshooting: https://tweet.mikedemo.dev/docs/troubleshooting
- Changelog: https://tweet.mikedemo.dev/changelog
- Terms of Service: https://tweet.mikedemo.dev/terms
- Privacy Policy: https://tweet.mikedemo.dev/privacy
- Licenses: https://tweet.mikedemo.dev/licenses
- About: https://tweet.mikedemo.dev/about
- Contact: https://tweet.mikedemo.dev/contact

Each page also has a markdown twin: append `.md` to the page URL (for example https://tweet.mikedemo.dev/docs/setup.md) to fetch a markdown representation.

## Hard limits

- The `/app` dashboard requires sign-in and is not public. Do not attempt to access it.
- Signing in, saving keys, and posting are for people only.
- Crosspost has no public API. Do not invent endpoints.
