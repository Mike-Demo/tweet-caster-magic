# Read Crosspost Documentation

Use this skill when you need to understand how Crosspost works: setup steps, posting behavior, X tokens and keys, security practices, or troubleshooting.

## What Crosspost is

Crosspost watches a tweet.app account and reposts new posts to X, automatically or after a quick review, using each person's own X developer keys. It is an independent service, not affiliated with X Corp. or Operation Bluebird, Inc.

## Documentation index

Start at https://tweet.mikedemo.dev/llms.txt for the full navigation index, then read the page you need:

- Setup guide: https://tweet.mikedemo.dev/docs/setup — connect tweet.app, choose the account to watch, add X keys, pick behavior.
- Posting: https://tweet.mikedemo.dev/docs/posting — automatic vs review-first, replies, quotes, long posts, waiting queue and history.
- Tokens and keys: https://tweet.mikedemo.dev/docs/tokens — the four OAuth 1.0a X values, the tweet.app access token, and how both are stored.
- Security: https://tweet.mikedemo.dev/docs/security — where keys and tokens are stored, how they are encrypted, who can use them, how to delete them.
- Troubleshooting: https://tweet.mikedemo.dev/docs/troubleshooting — fixes for 401 errors, rejected keys, missing posts, rate limits, sign-in problems.
- Changelog: https://tweet.mikedemo.dev/changelog — dated update history.

## Hard limits

- Crosspost has no public API. Do not invent endpoints.
- Signing in, saving keys, and posting are for people only. No skill performs these actions.
- Reading and indexing public pages is welcome.
